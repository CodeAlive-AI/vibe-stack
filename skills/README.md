# Agent Skills

Reusable instructions and tools for coding agents. Each skill directory contains a human-readable README and a `SKILL.md` entry point for agents.

## agentic-capacitor

Convert existing web apps to Capacitor 8.5, maintain iOS/Android integrations, and prepare for a later Capacitor 9 upgrade. Includes React 19.2 guidance and offline validation scripts.

- [README: installation, examples, validation, and limits](agentic-capacitor/README.md)
- [Agent instructions](agentic-capacitor/SKILL.md)

## apple-app-store-reviewer

Audit Apple-platform release candidates before App Store submission or resubmission, with deterministic checks, evidence-based review, Capacitor 8.5 coverage, privacy and payment checks, and remediation guidance. Apple makes the final approval decision.

- [README: setup, workflow, and validation](apple-app-store-reviewer/README.md)
- [Agent instructions](apple-app-store-reviewer/SKILL.md)

Moved in full from [ai-driven-development](https://github.com/CodeAlive-AI/ai-driven-development). This repository is now the canonical source; install `apple-app-store-reviewer` from `CodeAlive-AI/vibe-stack` instead of its former repository.
