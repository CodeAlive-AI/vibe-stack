# Agent Skills

Reusable instructions and tools for coding agents. Each skill directory contains a human-readable README and a `SKILL.md` entry point for agents.

## agentic-capacitor

Convert existing web apps to Capacitor 8.5, maintain iOS/Android integrations, and prepare for a later Capacitor 9 upgrade. Includes React 19.2 guidance and offline validation scripts.

- [Agent instructions](agentic-capacitor/SKILL.md)
