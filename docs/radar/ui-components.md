# UI Components Radar

## Default

### Mantine

Status: `default`

Mantine is the default product UI component system. It covers common application UI needs with a broad, documented component set.

## Exception

### Radix UI

Status: `exception`

Use Radix UI when a project needs a lower-level accessible primitive that Mantine does not provide, or when a project is intentionally building a custom design system.

Radix UI is not the default for normal product apps because it shifts more design-system work onto the team.

## Styling Layer

### Tailwind CSS v4

Status: `default`

Tailwind CSS is the default utility styling layer. It complements Mantine for layout, spacing, responsive composition, and app-specific polish.
